IMPORTACIÓN - 2 FASES (Preview + Confirm)
───────────────────────────────────────────

FASE: PREVIEW
─────────────
  POST /api/import/preview
         ↓
    [import.js preview()]
         ↓
    [import-auth middleware] → JWT ✓ + Admin ✓ + File valid ✓
         ↓
    Parsea archivo
    ├─ Si .xlsx → excel-parser.parseFile()
    └─ Si .csv  → csv-parser.parseFile()
         ↓
    [Arquitectura]
    excel-parser.parseFile()
        └─ Workbook → Worksheets → Rows → Headers + Data rows

    csv-parser.parseFile()
        └─ Raw CSV → Papa.parse() → Rows → Headers + Data rows
         ↓
    Mapea columnas
    data-mapper.mapRow(row, type) → Resuelve nombres de columnas
         ↓
    Valida datos
    validators.validateRows(rows, schema) → Zod schema validation
         ↓
    RETORNA (sin guardar nada):
    {
      importId: UUID,
      summary: { total, valid, invalid },
      preview: { valid_rows[], invalid_rows[] with errors }
    }
         ↓
    [Limpia temp file]


FASE: CONFIRM
─────────────
  POST /api/import/confirm
         ↓
    [import.js confirm()]
         ↓
    [import-auth middleware] → JWT ✓ + Admin ✓
         ↓
    Repite parseado + validación (igual que preview)
         ↓
    EJECUTA IMPORT (core logic en data-importer.js)
         ↓
    importModeloVersions(validRows, options)
    o
    importSucursales(validRows, options)
         ↓
         ├─ Para cada fila:
         │   ├─ Resolver referencias (modelo: nombre → ID)
         │   ├─ Buscar existencia (by unique field)
         │   ├─ Mode decision:
         │   │   ├─ create → Crear nuevo
         │   │   ├─ update → Actualizar existente (error si no existe)
         │   │   └─ upsert → Crear O actualizar (recomendado)
         │   ├─ strapi.entityService.create/update()
         │   └─ Publicar si está configurado
         │
         └─ Loguea resultado en collection import-log
         ↓
    RETORNA:
    {
      importId: UUID,
      status: 'completed' | 'completed_with_errors',
      summary: { created, updated, errors, total },
      errors: [...detailed error list],
      duration: 'X.XXs'
    }
         ↓
    [Limpia temp file]

MAPEO (Intelligent Column Matching)
───────────────────────────────────

Ejemplo: Excel tiene columna "Precio Lista (CLP)"

Proceso:
  1. Normalizar: "Precio Lista (CLP)" → "precio_lista_clp"
  2. Buscar match exacto en mappings → no encontrado
  3. Aplicar Levenshtein similarity → "precio_lista" (80% match)
  4. Si confidence > 60% → Sugerir "precio_lista"
  5. Si confidence < 60% → Mantener nombre original

Resultado: Row { precio_lista: 25000000 }
